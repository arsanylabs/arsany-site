Dentica Founder

Product · Closed beta · NestJS, Prisma, Postgres (Supabase), Better Auth, Expo, TanStack Query, Turborepo

Dental practice management for Egypt, for solo doctors and clinics, on web and mobile. Arabic-first, with a dental chart drawn as real teeth. I founded it and built it, and it is now in closed beta.

  • Dentica Web

    Dentica Web is the practice management platform in the browser. Built for solo doctors and for clinics in Egypt. One product for the doctor working alone and for the clinic with a team.

  • A Chart That Looks Like Teeth

    A full adult dental chart, drawn as real teeth, not boxes and letters. Conditions are painted on the exact tooth and the exact surface. Caries, fillings, crowns, implants, root canals, missing teeth. Fourteen conditions, each with its own colour and a three-letter mark, so colour is never the only signal. A 3D jaw view beside the 2D chart. And the chart is append-only: remove a condition and it stays in the history. Nothing clinical is ever destroyed.

  • Arabic First

    Arabic first, not Arabic also. English, Modern Standard Arabic, and Egyptian Arabic as its own language. The whole interface flips right to left. Priced in EGP, scheduled on Cairo time.

  • Everyone Sees Their Job

    Granular permissions, grouped into six plain-English bundles. Front desk, clinical, diagnosis and prescribing, billing, treatments, and more. Each one can be scoped to a single branch. A receptionist can run the front desk at one branch and see nothing at another. Every permission is written for the person ticking the box.

  • WhatsApp

    In Egypt, patients live on WhatsApp. The server queues the appointment reminders. Staff send them from their own WhatsApp, in one click. No consent, no message.

  • Day One

    No clinic should start from an empty database. Every new account begins with a curated treatment library. Then makes the price list its own.

  • 41 Tables

    Underneath it all, a 41-table data model. Soft deletes, so nothing a clinic records is lost by accident. Append-only history, so every change can be traced.

  • The API

    The API is NestJS. Prisma talks to Postgres. Postgres lives on Supabase.

  • Sign In

    Who gets in, and as whom. Sign-in runs on Better Auth.

  • One Repo

    Web, mobile and the API. One Turborepo holds them all.

  • Tested at Every Layer

    Unit tests with Vitest, for the logic on its own. API end-to-end tests that run against a real Postgres, not mocks. They cover sign-in, roles and permissions, patients, appointments, charting, invoices and payments. Even two people accepting the same invitation at once. Playwright drives the web app in a real browser: onboarding, sessions, invoices, WhatsApp, every language and accessibility. Jest for the mobile screens. And k6 load tests: baseline, stress, a full user journey, and a breakpoint run to find where it falls over, watched live in Grafana.

  • Dentica Lite

    Dentica Lite is the mobile app. Built with Expo, on iOS and Android. Same platform, same API, different access. It covers the day in the chair and at the front desk: the schedule, patients, charting, invoices and payments. What each person can do follows their permissions, never their job title. The heavy admin stays on the web.
